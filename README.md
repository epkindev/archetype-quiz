# Опитувальник архетипних патернів особистості

Готовий статичний PWA без залежностей, збірки та зовнішніх запитів.

## Локальна перевірка

1. Розпакуйте ZIP.
2. Відкрийте термінал у папці з index.html. Якщо встановлено Python: `python -m http.server 8000 --bind 127.0.0.1` (Windows також `py -m http.server 8000 --bind 127.0.0.1`). Це лише локальний сервер для перевірки, він не потрібен для публікації.
3. Відкрийте http://localhost:8000. Просте відкриття index.html як файла не активує PWA.
4. Надайте кілька відповідей, перезавантажте сторінку, натисніть «Продовжити тест».
5. Після повідомлення про готовність офлайн перезавантажте сторінку, потім увімкніть Offline у засобах розробника браузера → Network і перезавантажте ще раз.
6. Пройдіть усі питання. Перевірте повернення, зміну відповіді, результати та скидання.
7. Перевірте ширину 360 px, клавіатуру Tab / стрілки / Enter. У Chromium: Application → Manifest та Service Workers. Встановлення: меню браузера → «Установити застосунок», на iOS — Safari → Поділитися → На початковий екран.

## GitHub Pages

1. Створіть окремий публічний репозиторій, наприклад archetype-quiz.
2. Завантажте ВМІСТ цієї папки у корінь репозиторію, зберігши папку icons. index.html має бути в корені.
3. Збережіть файли комітом у гілку main.
4. Settings → Pages → Build and deployment → Source → Deploy from a branch.
5. Branch → main; Folder → / (root); Save.
6. Дочекайтеся успішного розгортання в Actions. Відкрийте адресу, показану в Pages: https://USERNAME.github.io/archetype-quiz/.
7. Відкрийте сайт онлайн до повідомлення про готовність офлайн. Встановіть застосунок через меню браузера.
   Офіційна інструкція: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Дані та підрахунок

90 тверджень перенесено без редагування формулювань із DOCX Косьянової О. Ю. та Карпич І. А. Розділено злиті в документі абзаци за номерами; прибрано лише пробіли навколо тверджень і службову нумерацію. Ключ витягнуто безпосередньо з таблиці. Усі пункти рахуються прямо, без інверсії. Кожен архетип містить 6 пунктів, сума 6–30. Шкала: 6 — Тіньовий; 7–12 — Слабко виражений; 13–18 — Присутній; 19–24 — Активний; 25–30 — Домінуючий. Повні описи взято з документа.
На межі топ/нижньої трійки включаються всі однакові бали. При повній рівності обидві групи містять усі 15 архетипів.
Збереження прив’язане до браузера та адреси сайту. Приватний режим чи очищення даних браузера можуть видалити прогрес. При забороні localStorage застосунок повідомляє про це й працює в пам’яті.

## Оновлення

При зміні файлів підвищіть версію CACHE у service-worker.js. Нова версія активується після закриття старих вкладок. Для повторного початкового кешування потрібне підключення до мережі.
